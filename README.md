# Ichnora AI / Fraud Hunter Web MVP

Актуальная версия 0.2: откройте **`index.html` в этой папке** двойным кликом. Она работает без установки, сервера и интернета. Все файлы `app.js`, `core.js`, `app.css`, `world.js` должны оставаться рядом. Главный ярлык `../overclock.html` ведёт сюда же.

Добавлены 100 000 синтетических операций, обученная базовая ML-модель, действующие пороги и метрики, поиск, фильтры, аудит, импорт/экспорт CSV, офлайн-карта мира, все 249 ISO-кодов стран и территорий, анализ связей.



Для сайта установка не нужна. Для автоматических проверок: `npm install`, затем `npm test`.

Папки `frontend/src` (React/Vite) и `backend` (FastAPI) ниже — **старые заготовки версии 0.1**. Они сохранены для будущей интеграции, но не используются актуальным локальным сайтом. Старый backend содержит rule-based демонстрацию, а не текущую обученную модель.

## Модули

- Dashboard — бизнес-метрики, распределение решений и компромисс между стоимостью и риском.
- Transactions — аудит операций и объяснение факторов риска.
- Live Demo — ручная проверка операции.
- Graph & Map — демонстрация связей и геоаномалий.
- Data Upload — рабочая загрузка и проверка CSV, пример файла, экспорт и восстановление демоданных.

## Запуск старой React-заготовки (не основной сайт)

```bash
cd frontend
npm install
npm run dev
```

## Запуск старой backend-заготовки

```bash
cd backend
pip install fastapi uvicorn pydantic
uvicorn main:app --reload
```

Актуальная локальная модель — логистическая регрессия, обученная на отдельной синтетической выборке. Объяснения показывают реальные вклады модели в log-odds. Это не SHAP и не LLM; результаты не являются проверенными оценками риска для реального банка.
